LocalNAS - Advanced Instructions

Note: This was developed on Windows 10, so the guide will use Windows 10 applications and terms.

Python

If you have download the source code for LocalNAS, you will need to install Python Version 3.13+ as LocalNAS runs on a Python program developed using Python 3.13. Once you installed all the dependencies/modules needed for the program to run.

  1. Open main.py
  2. Go to line 16 and change the password
  3. Open Terminal, and cd [path to main.py here]
  4. Type in python main.py Make sure port 8000 is open or else the server will not reach other network devices
  5. If port 8000 is already opened and your network is set to private, all other network devices should be able to access LocalNAS
You may need to install these dependencies/modules before running the program, which include: http.server, socketserver, os, shutil, secrets, hashlib, and hmac

To install the dependencies/modules:

  1. Open Terminal
  2. Type in pip install [dependency/module here]
  3. Wait for it to be completed, then you are finished

Firewall

Your computer may not have port 8000 opened or allowed access to other local network devices. You will need to create an inbound firewall rule to allow traffic on port 8000.

  1. Open Windows Defender Firewall with Advanced Security (search it in the Start Menu)
  2. Click Inbound Rules in the left panel
  3. Click New Rule... in the right panel
  4. Select Port and click Next
  5. Select TCP, enter 8000 in the specific local ports field, and click Next
  6. Select Allow the connection and click Next
  7. Make sure Private is checked (you may uncheck Public and Domain), then click Next
  8. Give the rule a name such as LocalNAS Port 8000 and click Finish
If LocalNAS still cannot be reached from other devices, also check the following: Network profile must be set to Private, Windows Defender Firewall must be enabled, and third-party firewalls or antivirus software may be blocking the connection

To set your network profile to Private:

  1. Open Settings and go to Network & Internet
  2. Click your active connection and select Private
  3. Restart main.py and try connecting again
